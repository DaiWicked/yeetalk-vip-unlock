面向 **YeeTalk 2.58.2**（`com.imback.palpal` / versionCode 1955）的 LSPosed 模块，在本地进程内把 VIP 状态翻转为已开通。

## 实测生效（真机验证）

| 能力 | 结果 |
|---|---|
| 个人主页 VIP 徽标 | ✅ |
| 自定义主页封面 | ✅ |
| 翻译功能的客户端 VIP 门控 | ✅ |

## 不生效（服务端裁决，改本地字段无意义）

- VIP 购买页「已开通」状态位
- 翻译次数配额（服务端按账号计次）

## 安装

1. 安装 `systools-1.0.0-release.apk`
2. LSPosed 管理器 → 模块 → 启用「**系统工具**」→ 作用域勾选 **YeeTalk**
3. **重启设备**（首次安装新模块必须重启，改配置库不生效）
4. 验证：`adb logcat -s XposedBridge | grep YTVIP`

## 已知限制

`H03` 访客解锁额度、`H04` 打招呼次数、`H05` 套餐页状态所对应的目标类被 R8 混淆成单字母，运行时无法按名字定位，这三个开关当前无效（模块内已如实标注）。

## 说明

模块只改变 **客户端读到本地状态后如何渲染**，不修改服务端、不伪造支付、不绕过计费。所有改动仅作用于本地进程内存与本地缓存展示。
